# Банковские операции - обработка данных

Этот проект предоставляет набор инструментов для обработки банковских операций, включая маскирование номеров карт и счетов, фильтрацию и сортировку операций по различным критериям.

## Функционал

### Маскирование данных

1. **Маскирование номеров карт**
   - Формат: `XXXX XX** **** XXXX`
   - Поддерживает строки и числа
   - Проверяет корректность номера (16 цифр)

2. **Маскирование номеров счетов**
   - Формат: `**XXXX` (последние 4 цифры)
   - Поддерживает строки и числа
   - Проверяет корректность номера (20 цифр)

3. **Функция `mask_account_card`**
   - Автоматически определяет тип данных (карта или счет)
   - Применяет соответствующую маскировку
   - Сохраняет название карты/счета

### Обработка дат

- Преобразование даты из формата ISO (`2024-03-11T02:26:18.671407`) в формат `ДД.ММ.ГГГГ`

### Фильтрация и сортировка операций

1. **Фильтрация по статусу**
   - По умолчанию фильтрует выполненные операции (`EXECUTED`)
   - Поддерживает любой статус (`CANCELED` и др.)

2. **Сортировка по дате**
   - По умолчанию сортирует по убыванию (новые сначала)
   - Поддерживает сортировку по возрастанию

## Тестирование

Проект включает комплексные тесты для всех функций:

### Тесты маскирования
- Проверка корректного маскирования карт и счетов
- Обработка некорректных данных (короткие/длинные номера, буквы)
- Проверка обработки чисел и строк с пробелами

### Тесты обработки данных
- Фильтрация операций по статусу
- Сортировка по дате (возрастание/убывание)
- Обработка операций без статуса
- Обработка пустых списков

### Тесты виджетов
- Интеграционные тесты функций маскирования карт/счетов
- Тесты преобразования дат
- Проверка обработки некорректных данных
